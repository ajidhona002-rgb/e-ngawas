Panel Admin

Kelola jadwal ujian semua kelas

Sambungkan ke Google Sheet (sekali saja):
  1. Buat Google Sheet baru di sheets.new, lalu buka Ekstensi → Apps Script.
  2. Hapus isi editor, tempel kode dari tombol di bawah, lalu klik Simpan.
  3. Klik Terapkan → Deployment baru, pilih jenis Aplikasi web. Jalankan sebagai Saya, akses Siapa saja, lalu Terapkan dan izinkan.
  4. Salin URL aplikasi web (berakhiran /exec) dan isikan ke API_URL di file index.html. Cukup sekali.
